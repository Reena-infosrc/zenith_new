Organizational Tree with SVG Connectors

Instructions:

  • Click the expand button (→) on any node to show its direct reports
  • Connectors use smooth cubic Bezier curves
  • Parent nodes remain static when children expand
  • Each level appears in a new column to the right

🔧 Tuning Instructions

1. Adjust Curve Softness

Modify the curveOffset parameter:

const connector = new OrgTreeConnector(container, {
    curveOffset: 80  // Change this value:
                     // - Lower (40-60): Tighter, sharper curves
                     // - Medium (70-90): Smooth, balanced curves (default)
                     // - Higher (100-120): Very soft, gentle curves
});

2. Support Many Connectors Dynamically

The component automatically handles any number of connectors:

// Each call to connect() adds a new connector
connector.connect(parentElement, childElement1);
connector.connect(parentElement, childElement2);
connector.connect(parentElement, childElement3);
// ... unlimited connections

// Remove specific connection
connector.disconnect(parentElement, childElement1);

// Remove all connections from a parent
connector.disconnectAll(parentElement);

// Clear all connections
connector.clear();

// Always call update() after DOM changes
connector.update();

3. Customize Appearance

const connector = new OrgTreeConnector(container, {
    curveOffset: 80,
    strokeColor: '#3b82f6',      // Start color (blue)
    strokeColorEnd: '#1d4ed8',  // End color (darker blue)
    strokeWidth: 2               // Line thickness (1-4 recommended)
});
